

TechStore — контракт Mock API



Мета



Описати можливий обмін даними між застосунком TechStore

та сервером магазину електроніки.



Це макет API для документації. У поточній версії TechStore

мережевий API не реалізовано. Дані товарів зберігаються

локально, а станом керує AppState через ChangeNotifier.



Базовий шлях: /api/v1



1\. Отримання товарів



Метод: GET

Адреса: /api/v1/products



Приклад відповіді:



{

&#x20; "products": \[

&#x20;   {

&#x20;     "id": "1",

&#x20;     "name": "Смартфон",

&#x20;     "description": "Сучасний смартфон 128 GB",

&#x20;     "price": 15999,

&#x20;     "imageAsset": "assets/images/phone.jpg"

&#x20;   }

&#x20; ]

}



2\. Отримання профілю



Метод: GET

Адреса: /api/v1/users/me



Приклад відповіді:



{

&#x20; "id": "1",

&#x20; "name": "Вівчар Вадим",

&#x20; "email": "v.vivchar@istu.edu.ua"

}



3\. Редагування профілю



Метод: PATCH

Адреса: /api/v1/users/me



Приклад запиту:



{

&#x20; "name": "Вівчар Вадим",

&#x20; "email": "v.vivchar@istu.edu.ua"

}



4\. Робота з обраними товарами



GET /api/v1/favorites

Отримати список обраних товарів.



PUT /api/v1/favorites/{productId}

Додати товар до обраного.



DELETE /api/v1/favorites/{productId}

Видалити товар з обраного.



5\. Робота з кошиком



GET /api/v1/cart

Отримати кількість товарів у кошику.



Приклад відповіді:



{

&#x20; "cartItemsCount": 2

}



POST /api/v1/cart/items

Додати товар до кошика.



Приклад запиту:



{

&#x20; "productId": "1"

}



DELETE /api/v1/cart/items

Очистити кошик.



6\. Обробка помилок



400 — некоректні дані користувача або товару.

404 — товар або користувача не знайдено.

500 — внутрішня помилка сервера.



7\. Взаємодія із застосунком



У майбутній реалізації відповіді API можуть

оновлювати дані AppState.



AppState повідомляє віджети про зміни через

notifyListeners(), після чого ListenableBuilder

оновлює відповідні частини інтерфейсу.
